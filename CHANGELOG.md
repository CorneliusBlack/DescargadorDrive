# Changelog

## 1.0.0 — 2026-10-10

Primera versión de producción validada.

### Incluye
- Gestión persistente de enlaces y estados.
- Selección de archivos en carpetas.
- Reanudación, reintentos y cancelación.
- Descargas públicas.
- Google Drive API mediante OAuth oficial para contenido autorizado.
- Protección del token local con Windows DPAPI.
- Revocación/desconexión.
- Notificaciones y sonidos configurables.
- Interfaz final de producción.
- Instalador Windows con conservación de datos de usuario.
